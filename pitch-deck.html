Pillar 02 • Technical Architecture • Slide 4 / 7

🧠 2. Technical Architecture: Dual-Layer Zero-Retention

📱 Layer 1: 100% On-Device Client PWA

  • ⚙️
    Dedicated Web Worker (js/worker.js): Mengisolasi kalkulasi NLP di background thread agar UI Keyboard Simulator tetap responsif 60 FPS.
  • 🧬
    Hybrid Indonesian Heuristic + Wasm AI: Memadukan mesin aturan pragmatik Bahasa Indonesia dengan model quantized Transformers.js v2.17.2 (distilbert-sst-2 ONNX/Wasm).
  • 📴
    Offline-First Service Worker (sw.js): Dapat diinstal di Android & iOS sebagai aplikasi mandiri dan bekerja 100% tanpa internet.

☁️ Layer 2: Hardened Google Cloud Run Backend

  • 🐳
    Node.js 24 Active LTS (node:24-alpine): Container produksi non-root dengan 0 paket node_modules (bebas risiko supply-chain attack).
  • ⚡
    Sub-3ms Stateless Bot Engine (server.js): Memproses webhook Telegram, Slack, dan REST API murni di RAM volatil (0 Database, 0 Disk Write).
  • 🛡️
    Hardened Guardrails (v5.3): Mitigasi CVE-2026-111497 ("Node2Shell"), V8 flags --disable-proto=delete, & Zero-PII SHA-256 Rate Limiter.
